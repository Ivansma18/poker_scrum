# Final Options Expected Output

```text
Perfect, the final spec is confirmed.

What do you want to do now?

A. Only create the spec.
B. Create the spec and apply it.
C. Only show it.
```

If the user chooses `A` or `B`, the spec must be created in `docs/` with an English, lowercase, kebab-case filename related to the spec.

Expected confirmation example:

```text
Spec created at `docs/save-product-favorites.md`.
```
