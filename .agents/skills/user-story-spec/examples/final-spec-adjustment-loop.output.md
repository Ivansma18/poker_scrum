# Final Spec Adjustment Loop Expected Output

```text
What part do you want to adjust?

A. Context
B. Objective
C. Scope
D. Functional requirements
E. Technical requirements
F. Acceptance criteria
G. Risks / tradeoffs
H. Applicable skills or Skill-based validation
I. Other
```

After receiving the adjustment, the assistant must update the spec, show it again, and ask:

```text
Do you agree with this final spec?
```
