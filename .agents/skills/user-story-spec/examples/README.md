# Examples

This folder contains examples that show how the skill should behave.

Use `examples/` for:

- Real or simulated inputs.
- Expected outputs.
- Correct cases.
- Incorrect cases.
- Edge cases.
- Product spec examples.
- Refinement or review examples.

Practical rule:

- If it helps understand how the skill should behave, put it in `examples/`.
- If it is reusable knowledge for reasoning or validation, put it in `references/`.
- Prefer paired files when useful: `<scenario>.input.md` and `<scenario>.output.md`.
