# Assets

This folder contains reusable files the skill can copy, reuse, or transform as part of its output.

Use `assets/` for:

- Templates.
- Base formats.
- Reusable snippets.
- Diagrams.
- Images.
- Static files.
- Report templates.
- Spec templates.

Practical rule:

- If the skill copies, reuses, or transforms a file as part of the output, put it in `assets/`.
- If the file explains how to reason or validate, put it in `references/`.
- If the file demonstrates expected behavior, put it in `examples/`.

Current assets:

- `spec-template.md`: canonical specification template for this skill.
